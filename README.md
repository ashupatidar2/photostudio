# Ashu Patidar Photography - Editorial Luxury & Cinematic Refinement 🎞️✨

A high-end, image-first photography studio management application. Transformed from a standard portfolio into a **Cinematic Masterpiece**, this project prioritizes visual storytelling, sophisticated typography, and buttery-smooth user experiences.

## 🌟 The Vision: "Editorial Luxury"
This project has been elevated beyond a standard web replica into a sophisticated digital portfolio inspired by premium fashion magazines and luxury cinematic photography.

### Key Refinements:
- **Cinematic Motion**: Integrated **Lenis Smooth Scroll** and **GSAP ScrollTrigger** for a premium, flowing experience.
- **Editorial Typography**: Strategic use of **Cormorant Garamond** and **Playfair Display** for a sophisticated "Magazine Cover" aesthetic.
- **Artistic Layouts**: Dynamic **Masonry/Pinterest-style** galleries that break away from rigid grids.
- **Visual Depth**: Implementation of "Brush Stroke" and "Torn Paper" image masks along with parallax backgrounds.

## 🚀 Core Features

### 🎞️ Cinematic Public Experience
- **Hero Masterpiece**: Large-scale image reveals with overlapping editorial typography.
- **Smart Portfolio**: Category-filtered masonry galleries (Wedding, Pre-Wedding, Maternity, etc.).
- **Interactive Storytelling**: Section reveal animations that respond to scroll depth.

### 📝 Luxury Booking System
- **Step-by-Step Guidance**: A redesigned booking experience with smooth GSAP transitions.
- **High-Contrast UI**: Premium dark theme with custom `.luxury-input` controls for perfect visibility.
- **Calendar Integration**: Intuitive date and time selection for seamless scheduling.

### 🛠️ Technical Prowess
- **Full-Stack Power**: FastAPI (Python) backend with PostgreSQL and SQLAlchemy.
- **Modern Frontend**: React 18, Vite, and Tailwind CSS.
- **Image Intelligence**: Automatic thumbnail generation and multi-format support (WebP/PNG/JPEG).

## 🚀 Quick Start

1. **Backend**:
   ```bash
   cd backend && pip install -r requirements.txt
   uvicorn app.main:app --reload
   ```

2. **Frontend**:
   ```bash
   cd frontend && npm install
   npm run dev
   ```

*For detailed setup instructions, please see [QUICKSTART.md](./QUICKSTART.md).*
